# Akash Chouhan — Portfolio (Frontend)

React + Vite + Tailwind CSS portfolio application for Akash Chouhan.

- **Live Site**: [https://akashchouhanportfolio.netlify.app/](https://akashchouhanportfolio.netlify.app/)
- **Main Documentation**: Refer to the root [`../README.md`](../README.md) for full resume details, projects, tech stack, and achievements.

### Development Commands

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```
