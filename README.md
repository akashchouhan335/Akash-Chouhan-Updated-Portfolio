## 💻 About This Portfolio Repository

This repository contains the source code for Akash Chouhan's interactive personal portfolio:
- **Design**: Minimalist monochrome aesthetic with ambient glow effects, 3D flip card, and smooth GSAP typography reveals.
- **Interactive 3D**: Molten metal interactive background and interactive profile card.
- **Form Handling**: Integrated with Netlify Forms (zero-backend, serverless submission handling with honeypot spam protection).
- **Deployment**: Configured for continuous deployment from GitHub to Netlify.

### 🏃 Quickstart / Local Development

```bash
# Clone the repository
git clone https://github.com/akashchouhan335/portfolio.git
cd "Akash Chouhan Portfolio Redesign/portfolio"

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
